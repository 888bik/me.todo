# 待办（me.todo）

Win顺 的桌面待办便签插件。常驻运行，搜索框输入 `db` 即可在 Win顺 结果中直接查看待办清单；输入 `db` 加新内容可以添加待办。桌面常驻一张便签，托盘菜单控制显隐。当前版本支持重复提醒、截止日期、标签、子任务、日历视图、导入导出和锁定穿透；3.0.3 增加跟随 Win顺 外观主题和更顺滑的搜索交互；3.0.4 增加紧急解锁热键并修复隐藏/重新显示时的穿透恢复顺序；3.0.5 保留用户调整后的窗口尺寸并优化列表入口和视图导航；3.0.6 复用详情窗并让月视图“更多”弹窗可滚动；3.0.7 补全鼠标钩子的 64 位 Win32 声明并让取消父任务不再清空子任务；3.0.8 修复钩子线程换代竞态，并让已完成的重复任务不再占后续日历；3.1.0 增加智能快速输入和便签筛选/搜索运算符；3.2.0 换成左侧导航 + 主区的现代外壳，并加入紧凑模式和高 DPI 地基；3.2.1 增加键盘导航提示，添加待办后弹出便签确认；3.2.2 快速输入支持重复、中文数字、指示词和不带钟点的时段词；3.3.0 把详情搬进右侧栏，并让月视图点日期在右栏列出当天任务；3.3.1 让重复日期直接跳到目标区间、提醒批量落盘，并让剩余弹窗单实例；3.4.0 列表和今日视图改为只渲染可见行的虚拟列表；3.4.1 在界面设置里增加透明度滑杆；3.4.2 修复详情侧栏滚轮卡顿；3.4.3 让详情栏的优先级/置顶即选即存，并把保存按钮固定到底部；3.4.4 放大任务行右侧操作图标；3.4.5 恢复虚拟列表丢失的 18px 子任务缩进。

## 用法

搜索框里两个关键词，行为完全一样：

| 输入 | 结果 |
|---|---|
| `db 买牛奶` | 结果行「新建待办：买牛奶」，回车添加并提示「已添加：买牛奶」；同时提供打开完整窗口的入口 |
| `db` | 直接显示现有待办列表（最多 8 条），并提供「打开完整待办窗口」入口 |
| `todo 买牛奶` / `todo` | 同 `db` |

输入文字时，会先列出**匹配的已有待办**（最多 8 条；子串匹配，拉丁字母不分大小写），并提供「打开完整待办窗口」和最后的「新建待办：xxx」。每条副标题写明回车会发生什么：`回车标记完成 · 截止 明天 09:00 · 每天`，已完成的显示 `已完成 · 回车取消完成`。回车即勾选/取消勾选，并提示「已完成：xxx」或「已取消完成：xxx」。

结果最后一行是**不可选中的键盘导航提示**：`Ctrl+N 向下 · Ctrl+P 向上 · Ctrl+1~9 直达第几行`，副标题「回车确认当前选中行」。它只提示，回车不会选中它。无论 `db` 后面有没有文字都会加这一行。

从 WinShun 添加（普通添加或快速输入预览）成功后，除了保留「已添加：xxx」提示，还会把桌面便签弹到前面让你看到新待办，但**不抢键盘焦点**。

桌面便签（默认普通窗口层级；锁定时才始终置顶）：

- 每行默认只显示复选框、文字、截止时间、标签和优先级 pill（高红 / 中橙 / 低灰）；鼠标悬停或键盘焦点落到行上才出现 `···` 详情、`⏰` 提醒、`＋` 新建子任务（仅顶级）、`✕` 删除；置顶行文字前加 📌。
- 有标签的行在文字下方显示 `#工作 #学习`；有备注的显示 📝；有子任务的行显示「子任务 1/3」。
- 列表顺序：置顶在前，再按优先级高→低、截止时间从早到晚，没截止的垫底，已完成的沉底；子任务紧跟父待办。只影响显示，`todos.json` 仍是写入顺序。
- 逾期（未完成且已过有效截止）的截止小字变红；不加定时刷新，下一次自然重绘时更新。
- **单击行**在右侧详情栏打开它（双击同样打开）；详情里可改标题、截止、提醒、标签、优先级、备注等。
- 有已完成待办时，主区顶部右侧出现「清除已完成」，点一下删掉全部完成项。
- 删除（单条、父级连带子任务、清除已完成）后状态栏显示「已删除 N 条」和「撤销」，可撤销一次，5 秒后入口自动消失。
- 底部输入框回车添加；输入里的 `#标签` 会被抽出来存成标签（最多 5 个，去重，1–10 字）。
- 已完成项显示删除线并变灰，仍留在列表里，不自动删除。
- 待办多到超出窗口时，右侧滚动条可用、鼠标停在任意一行上都能滚轮下拉；内容装得下时滚动条禁用、滚轮不动。
- 右上角 X **把便签藏到托盘**（和 QQ/微信点 X 最小化一样），不退出进程、不弹确认框；待办存在 `todos.json` 里不会丢，托盘菜单或全局热键随时叫回来。
- 标题栏右侧的 ⚙ 打开「界面设置」：**界面字号**（9–14，默认 10）、**紧凑模式**复选框和**窗口透明度**滑杆（50–100%），保存后立即生效，记在 `config.json` 里。字号、紧凑模式和这个透明度滑杆都不在 WinShun 内置设置页里。
- 全部文字用微软雅黑；标题 = 字号 +2 加粗，正文/输入框/按钮 = 字号，截止时间与计数 = max(8, 字号−1)，状态栏 = max(8, 字号−2)。
- 插件卡片用和官方插件一致的**单色线性图标**（`icon.png`，深色主题用 `icon.dark.png`）；便签窗口自己用蓝色勾选图标 `sticky.png` / `icon.ico`。窗口带 `WS_EX_TOOLWINDOW` 且改完样式后补一次 `SetWindowPos(SWP_FRAMECHANGED)` 刷新，**不出现在任务栏和 Alt+Tab 里**，只从 Win顺 托盘菜单或全局热键打开。
- 齿轮「界面设置」和提醒日历都相对便签居中弹出，不再跑到屏幕左上角。
- 鼠标移到某一行上，卡片边框会加深一点，并显示 `··· / ⏰ / ＋ / ✕` 操作；键盘焦点落到行上也会显示。
- 搜索框在主区顶部：输入即过滤（文字、标签、`#标签`、`is:`/`due:`/`priority:` 都能搜），Esc 清空；四个视图都按同一个结果过滤。
- 左侧导航上半是 6 个筛选，下半是「周视图 / 月视图」，见下面的「新界面（3.2.0）」。
- 位置和窗口大小都会记住（存 `config.json`），默认 720×520、最小 600×420；保存宽度小于 600 时显示会钳到 600。切换筛选/日历不再改变窗口尺寸。
- 窗口跟随 Win顺 的深浅色主题；宿主提供 `nativeLook` 时同步使用其背景、文字、边框、强调色和危险色。旧宿主或没有完整外观信息时回退到内置浅色/深色配色。
- 搜索输入增加 110 ms 防抖，避免每个按键都完整重建列表；有搜索内容时显示一键清空按钮。

托盘菜单（标题「待办」）：

- 「显示便签 / 隐藏便签」，勾选状态表示当前是否显示。
- 「锁定便签 / 解锁便签」，勾选状态表示是否锁定穿透。
- 「新建待办」：显示便签并把光标放到输入框。
- 「紧凑模式」，勾选状态表示当前是否单行紧凑显示。
- 「完成统计」「导出待办…」「导入待办…」。

全局热键：默认 `Ctrl+Alt+T`，**切换**便签的显示/隐藏——可见时藏起来，不可见时叫出来并聚焦输入框（锁定时不聚焦输入框）。独立保留 `Ctrl+Alt+U` 作为**紧急解锁**热键，即使便签完全鼠标穿透也能解锁。优先请 Win顺 代注册（`register_hotkeys`），注册失败会在 300 毫秒后重试一次；改设置后立即重新注册。

提醒：

- 每行 ⏰ 打开「提醒」：点日期、选**时、分**，再选**重复**（不重复 / 每天 / 工作日 / 每周 / 每月），点「保存」或「清除」；底部还有「10分钟后 / 30分钟后 / 1小时后」贪睡（只挪提醒时间，不改重复排期）。新建默认明天 09:00，Esc 等同取消。
- 详情栏里的「设置截止」打开的是**截止模式**：没有重复和贪睡，只改截止时间。
- 后台每 30 秒检查一次；**同一批到点的合并成一条通知**（标题「待办提醒」或「待办提醒（N 条）」，正文把几条文字拼起来、超过 200 字截断）——Win顺 每个插件每 2 秒只保留最新一条通知，逐条发会丢。点通知回到搜索框并填入 `db `。
- 到点会播一次系统提示音（可在设置里关掉）；一批只播一次。
- 一次性提醒只响一次；重复提醒到点后按 `repeat_base` 排下一次，贪睡不会让排期漂移。

## 重复提醒

- 四种：**每天**、**工作日**（周一至周五）、**每周**（勾选一至多个星期几）、**每月**（1–31 号）。
- 每月 31 号遇到小月按当月最后一天算，但下一次仍按 31 号：1/31 → 2/28 → 3/31，不会漂移成 28 号。
- 在列表里显示成「截止 … · 每天 / · 工作日 / · 每周一、三、五 / · 每月15日」。
- **勾选完成会生成下一条**（同文字、标签、优先级、置顶、备注、重复规则）：锚点还在未来就用锚点，否则往后排下一次；旧的那条保持完成态，用于统计。取消完成不会删掉已经生成的下一条。
- 已完成的重复任务只显示到完成当天，之后由新生成的那条接替；旧记录的 `repeat` / `repeat_base` 仍保留在详情里。

## 周/月视图

- 左侧导航下方「周视图 / 月视图」切换；最后用的视图记在 `config.json` 的 `view` 里，重启保持。
- 窗口默认 720×520、最小 600×420；位置记忆、锁定置顶、透明度、任务栏隐藏、X 藏托盘都不受影响。普通模式不强制置顶；只有锁定时置顶。日历视图不显示底部输入框，切回列表即可添加。
- **周视图**：周一至周日 7 列，今天那格浅蓝；「‹ / 本周 / ›」翻周；点标题就是勾选/取消。
- **月视图**：6×7 网格，只给当月真实日期画格子（月首/月末的空白日不画边框，不足 6 行的月份也不渲染空的第 6 行），今天高亮；每格最多 2 条标题，多的显示蓝色「+N 更多」；点日期格子或「+N 更多」都会在右侧栏列出当天全部任务（可滚动），点其中一条切到它的详情，不会误勾选或新建任务；同一时间只有这一个右栏。「‹ / 本月 / ›」翻月。
- 日历只显示有提醒或截止的待办（含已完成，带删除线）；底部会提示「另有 N 条无提醒待办，仅在列表视图显示」。点空白日期不会新建，拖拽也不做。

## 今日

- 左侧导航「今日」：只显示今天到期、或今天有重复 occurrence 的待办；今天到期的已完成也保留（带删除线）。
- 上方小字「逾期 X · 今日到期 Y」分别统计逾期条数和今日到期条数；逾期不再混进今日列表。

## 锁定与穿透

- 标题栏 🔓 / 🔒 按钮切换锁定；锁定时窗口加 `WS_EX_TRANSPARENT`，鼠标点穿便签，所有按钮都点不到。
- 解锁方式：**Ctrl + 双击便签**（Win32 低级别鼠标钩子，只有落点、Ctrl、双击时间/距离都满足才触发）；也可以使用独立全局热键 **Ctrl+Alt+U**，或托盘菜单「解锁便签」。
- 钩子装在独立的守护线程里、自带消息泵；回调只读缓存的窗口矩形并投递解锁命令，**绝不调用 Tk**（跨线程调 Tcl 会把鼠标卡死）。
- 万一钩子装不上，锁定后窗口保持可点击（不完全穿透），锁按钮和托盘仍能解锁，不会把人锁死。
- 锁定时状态栏提示「已锁定：点穿便签，Ctrl+双击解锁」；热键叫出便签时不聚焦输入框。锁定状态存 `config.json` 的 `locked`。

## 标签与子任务

- 添加时 `#工作` 这类词会变成标签（最多 5 个，去重）。
- 行右侧「＋」在父行下方插入子任务输入框（Esc 取消、回车创建、空内容不创建）；子任务缩进 18px，紧跟父待办，行上没有「＋」。
- 父行显示「子任务 1/3」；勾父任务会把子任务一起完成；取消父任务只打开父任务，子任务保持原样（已完成的仍完成、完成时间不动）；单独勾子任务不影响父任务。删父待办会连子任务一起删，撤销整批恢复。
- WinShun 搜到子任务时，副标题以「所属：<父文字> · 」开头。

## 详情与备注

- 单击任务行（或点 `···`）在窗口最右侧打开 300px 详情栏；再点别的行会直接切换过去。双击行也是同一行为。
- 详情栏包含：标题、优先级（无/低/中/高）、置顶、截止（设置/清除）、提醒/重复（设置/清除）、标签（逗号分隔）、备注（多行）、子任务列表、完成/取消完成、删除。
- **优先级和置顶选完立即保存**（只写该字段，不会覆盖正在输入的标题/标签/备注）；标题、标签、备注和截止/提醒的文本修改仍点底部的「保存」。
- 「保存 / 删除 / 完成」固定在详情栏底部，不随内容滚动；切到「当天任务」时不显示这三个按钮。
- 点右上角 ✕ 收起详情栏，窗口恢复到打开前的宽度；窗口加宽不会超过屏幕宽。
- 关闭栏不会提交未保存的标题/标签/备注；截止与提醒仍是选择时立即写盘。
- 有备注的行显示 📝。

## 月视图点日期

- 点月视图的某一天（日期数字或空白格子），右侧栏切到「当天任务」，列出那天全部任务，可滚动。
- 点其中一条，右侧栏切到那条任务的详情；不会弹独立窗口，也不会误勾选。
- 格子里的「+N 更多」同样打开当天列表；旧的“更多”弹窗已移除。

## 截止与提醒分开

- 提醒弹窗的「截止日期」模式只改 `due_at`，不碰提醒；列表、排序、逾期、日历、今日视图、搜索副标题都用「有效截止 = due_at，没有就用 remind_at」。
- 只设截止不设提醒的待办不会弹通知，只在逾期后标红，并出现在日历/今日视图。
- 两者都有时，搜索副标题写截止时间，若提醒时间不同再追加「· 提醒 <时间>」。

## 导出 / 导入

- 托盘菜单「导出待办…」写一个 JSON（`{"version":1,"exported_at":…,"todos":[…]}`，含全部字段），默认文件名 `todos-YYYYMMDD-HHMM.json`。
- 「导入待办…」读 JSON、逐条清洗、按 id 去重后合并，只追加不删除；导入结果显示在状态栏。
- 文件损坏或格式不对时什么都不改，状态栏提示导入失败。

## 完成统计

- 托盘菜单「完成统计」打开小弹窗：今日完成、本周完成（周一到周日）、本月完成、累计完成、连续完成天数。
- 连续天数从今天往回数；今天还没完成就从昨天开始数。
- **只统计当前 `todos.json` 里还在的待办**：清掉的已完成不会进统计。

## 提醒声音

- 设置里「提醒时播放提示音」默认开；到点时用 `winsound.PlaySound("SystemAsterisk")` 播一次系统提示音，一批只播一次，失败静默；非 Windows 跳过。

## 智能快速输入

`db` 后面可以直接写自然语言，先出现预览行，回车才添加：

| 输入 | 结果 |
|---|---|
| `db 明天下午3点开会` | 开会，明天 15:00 |
| `db 周五交项目报告 #工作` | 交项目报告，本周五，标签 工作 |
| `db 这个月20号缴费` | 缴费，本月 20 号 |
| `db 3天后 !! 交报告` | 交报告，三天后，优先级中 |
| `db 三天后开会` | 开会，三天后（也认两天后、十天后） |
| `db 这个周五开会` | 开会，本周五（这/那/下个 也会剥掉） |
| `db 每天开会` / `db 每周五开会` | 开会，每天重复 / 每周五重复 |
| `db 每月1号交房租` | 交房租，每月1号重复 |
| `db 明天下午开会` | 开会，明天 15:00（不带几点钟的时段词） |

支持日期（今天/明天/后天/大后天、阿拉伯或中文数字的 N天后、周X/星期X、本周X、下周X、下周、X号、这个月X号、下个月X号、下个月、X月X号）、时间（上午/中午/下午/晚上/凌晨/半夜 X点、X点半、X点Y分、X:Y）、不带几点钟的时段词、`#标签` 和 `!`/`!!`/`!!!`（可贴在词头/词尾，超过 3 个按 3 算；全角 `！` 不算）/`紧急`。只有日期时提醒 09:00、截止 23:59；只有时间时取今天，已过则顺延到明天。

重复写法：`每天`、`工作日` / `每个工作日`、`每周X`、`每周`、`每月X号`、`每月`。有明确日期时首次出现用那个日期；每月X号沿用 X号 规则（本月已过取下月）。时段词默认：早上/上午 09:00、中午 12:00、下午 15:00、晚上 19:00、凌晨 06:00、半夜 00:00；同一句里有明确几点钟时以明确时间为准。

预览行下面是「直接添加原文」行，用于纠错；什么都没识别出来时和原来的新建待办完全一样。

## 筛选与搜索运算符

左侧导航的筛选：今日 / 逾期 / 全部 / 未来7天 / 无截止 / 已完成，当前项高亮。筛选只作用于列表和今日，周/月日历仍按日期展示；筛选与便签内搜索叠加，任务数显示筛选后的条数。筛选状态写进 `config.json` 的 `filter`，重启恢复。

WinShun 搜索和便签内搜索共用这些运算符（所有词 AND）：

- `is:done` / `is:open`
- `due:today` / `due:tomorrow` / `due:overdue` / `due:week` / `due:none`
- `priority:high` / `priority:medium` / `priority:low` / `priority:none` / `priority:0`–`priority:3`
- `#标签`（只匹配标签）

不认识的 `x:y` 会当普通文字搜索，不会丢词。例如 `db #工作 is:done`、`db due:today priority:high`。

## 设置

用 Win顺 内置的插件设置页（manifest 的 `settings[]`），改完立即生效，不用重启：

| 设置 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 启动时显示桌面便签 | bool | 开 | 关掉后便签只在托盘/热键时出现 |
| 便签不透明度（50–100） | number | 95 | 低于 50 按 50，高于 100 按 100 |
| 新建待办全局热键 | hotkey | Ctrl+Alt+T | 用来显示便签并聚焦输入框 |
| 提醒时播放提示音 | bool | 开 | 用系统提示音，不新增权限 |

界面字号、紧凑模式和透明度覆盖值不在这里，用便签标题栏的 ⚙ 设置（保存到 `config.json`，不进 WinShun 设置页）；锁定状态也存在 `config.json`。WinShun 设置页的「便签不透明度」仍作为初始/回退值：在便签齿轮里调过之后，以 `config.json` 的 `transparency` 为准。

## 权限

只申请两项：

- `ui`：开便签窗口、代注册全局热键。
- `notifications`：发提醒的系统通知（没有就当底栏提示）。

不联网、不读剪贴板、不读写用户文件，不申请 `processes`、`files:*`。

## 数据

只写 `WS_DATA_DIR` 下的两个文件：

- `todos.json`：待办列表，每条含 `id`、`text`、`done`、`created_at`、`remind_at`、`reminded`、`repeat`、`priority`、`pinned`、`tags`、`parent_id`、`note`、`due_at`、`completed_at`、`repeat_base`。
- `config.json`：便签窗口位置（`window_x` / `window_y`）、窗口尺寸（`window_width` / `window_height`）、界面字号（`font_size`，9–14）、当前视图（`view`：`list` / `today` / `week` / `month`）和锁定状态（`locked`）。

`todos.json` 损坏时先备份成 `todos.json.bak`，再从空列表开始，不崩。没有聊天记录、没有密钥、没有网络请求。

## 已知限制

- **提醒只在插件进程活着时才会响**：Win顺 关掉，插件进程就结束，提醒不会响。下次启动时已经过期的未提醒项会补发一次。
- 关机期间错过的重复提醒不会逐次补发，只会从当前时间往后排下一次。
- 撤销只保留最近一次删除（含整批清除已完成），存在内存里，重启后失效；入口 5 秒后自动收起。
- 点 X 或托盘「隐藏便签」都只是把窗口藏起来，进程仍在（`idleExitSec: 0`），否则提醒和热键都会失效；真正退出要关掉整个 Win顺。
- 热键依赖宿主的 `register_hotkeys` 能力；旧宿主不支持时会记录日志并放弃，不会退回到插件自行注册。
- 完成统计只算当前 `todos.json` 里还在的待办；清掉的已完成不进统计。
- 锁定穿透依赖 `WS_EX_TRANSPARENT`（便签本身是 layered 窗口）；钩子装不上时仍可从托盘解锁，不会卡死。
- 提醒声音用的是系统自带 `SystemAsterisk`，系统禁音或静音时听不到；非 Windows 平台直接跳过。

- 点空白日期不会新建待办，也不支持拖拽；改重复仍要从列表行的 ⏰ 进弹窗。
